Services · one specialty

We do one service. On purpose.

Lawn rehabilitation. That's all we do and that's all we book.

The package

Three-step rehab.
Single visit. Organic end-to-end.

  • Dethatching · all grass types
  • Core aeration · 3" plugs
  • Organic compost top-dress · ½"
Component 01
Dethatch

Strip the thatch. Reach the soil.

Mechanical dethatcher lifts the dead mat between the grass blades and the soil surface. Most Central Florida lawns have a thatch layer half an inch or more.

Component 02
Aerate

Pull plugs. Let the root zone breathe.

Three-inch plugs across the entire lawn. Florida soil compacts hard; roots need the airspace that compaction took away.

Component 03
Dress

Top-dress. Rebuild the living layer.

Half an inch of organic compost. Feeds the microbes that feed the grass. Only service a healthy lawn actually needs yearly.

What we don't do

Things we'll point you elsewhere for.

Weekly mowing
Healthy lawns need consistency. We're project-based.
Pest + weed spraying
Not our model. Good soil is the long-term weed plan.
New sod installation
If the soil's wrong, new sod fails. Rehab first.
Landscape design
Grass is our lane. We stay in it.

What changed for mobile

  • Metadata rail collapses from sticky left column to a horizontal meta-row under the nav. File number, voice, and one data point — the rest is implicit.
  • Soil-strata hero becomes a compact strata rail: four horizontal bands with layer name + depth/state. Preserves the signature without burning 800px of vertical space on an unscrollable diagram.
  • Service area ledger goes from three-column dark table to stacked dark cards. Each card has title + data-row below. Same visual language, narrow-friendly.
  • Trust band marquee ports unchanged — animation survives narrow widths natively.
  • Component cards swap from horizontal "number · title · desc · meta" layout to vertical stack. Big numerals (01/02/03) anchor the card instead of sitting in a column.
  • Chip-selector form stays as-is. It was built for touch — 44px min-height, wrap-flow, tap-to-toggle. Mobile is where it's best.
  • "What we don't do" table stacks what / why vertically instead of two columns. Same dark panel, same positioning play.

Patterns that gate on mobile (see gap catalog)

  • soil-strata-hero — desktop-only in its full strata form. Mobile uses the compact chip rail above.
  • interactive-process-stepper — sticky-left-nav pattern doesn't port. Needs a horizontal chip bar + scroll-snap panels variant for mobile. One-time component work.
  • annotated-soil-cross-section — the side-by-side "acts here →" arrow metaphor breaks when stacked. Needs a mobile diagram rework — likely a callout-stacked variant.
