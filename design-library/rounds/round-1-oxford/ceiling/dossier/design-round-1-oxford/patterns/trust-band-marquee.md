# Saturday Morning trust band marquee

`trust-band-marquee`

| Field | Value |
|---|---|
| Scale | **Systemizable** |
| Mobile | ✓ Ports cleanly |
| Voice assignment | Saturday Morning |
| Pages used | Home |

## Purpose

Accent-colored band of scrolling trust phrases. Voice-tuned per trade. Replaces logo strips contractors can't fill.

## Rationale

Infinite-scroll trust phrases on accent-colored band. Phrase list tagged to trade in voice config. Replaces logo bars contractors can't fill.

## Replaces (from F3 / F5 / F6 flagship)

F3/F5 have placeholder logo strips. F6 has no equivalent.

## Structural outline

```html
<div class="trust-band">
  <div class="row">
    <span>On time, every time</span>
    <span>·</span>
    <span>No upsells</span>
    …
    <!-- duplicated for seamless loop -->
  </div>
</div>
```

## Design tokens used

--lawn-500 (bg), --lawn-900 (text + borders), --f-mono 0.78rem 0.08em ls uppercase. Animation: `trust-scroll 36s linear infinite` translating -50%.

## Behavior notes

CSS-only infinite scroll. Pauses on hover. Respects prefers-reduced-motion (static display, no scroll).

## Responsive notes

No layout change. Font steps down one size at <600px.

## Constraints

Phrases come from voice-config tagged to trade. 6–10 phrases ideal. Every phrase should be a real client-style claim, not marketing generic.

## Code conversion notes

Phrases array generated by voice skill per trade + voice pair. Duplicated in DOM to make the loop seamless (content + content2). Animation distance = -50% of total width.
