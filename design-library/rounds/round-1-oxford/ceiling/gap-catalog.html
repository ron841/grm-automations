A direct reading of the gap vs the current flagship

What the F6 flagship is missing, honestly.

Voice

The flagship reads as a single voice throughout. The ceiling assigns a voice per section and tags it on the page, which is why the Closing Table-ness of the thesis feels different from the Front Porch-ness of About. This is free. We're already using the voice skill.

Typography

Flagship uses Space Grotesk + Inter. Clean, generic, reads SaaS. Ceiling uses Newsreader + JetBrains Mono + Public Sans, which reads editorial. Offer as a trade-class variant: "editorial specialist" palette vs "operations-forward" palette.

Structure

Flagship is section-stacked. Ceiling is asymmetric editorial grid with a sticky metadata rail. The rail is the single biggest systemizable gap. Once it's built, every future contractor site gets it for free.

Honest caveats
  • — The soil-strata motif is the most beautiful part of the ceiling. It will not save you on electrician #1. Budget for the rail and the stepper; enjoy the strata on Oxford only.
  • — Editorial tone lands for specialists with a story. For 24-hour emergency trades, we need a second typographic system. That's a separate ceiling exercise.
  • — Photography is the single lever that can break all of this. Even the cleanest layout needs real photos. Keep the GMB + Instagram ingestion pipeline healthy.
  • — The review-theme index requires a build-time NLP pass. If that pipeline isn't built, skip it. The rest of the site still works.
