Round 1 — Typographic Class Sketches · v1

Three headline systems.
One voice engine.

The library's 22 patterns work because Oxford has a distinct voice ("Closing Table," editorial, landowner-confident). Prospects without that voice need different type. These are headline-system sketches for Operations-Forward and Emergency-Urgent archetypes, shown next to the Oxford editorial reference — not full site rebuilds. Judge whether the type classes feel like three real products, not three themes of one.

Class A · Editorial-specialist Reference (Oxford)
Oxford Lawn Co. · Issue 04 · Spring

The lawn is not the project. The soil is.

Four generations of Upper Chester County turf. We work the thirty-two inches beneath your Kentucky bluegrass the way a vineyard works a terroir — slowly, seasonally, on record.

By E. Prentice · Founder Read · 4 min Filed under: Philosophy
Display face
Newsreader (400 / 300 italic) — literary serif with soft optical sizing. Proxy for a licensed face (Chronicle / Mercury) at production.
Body / UI
Public Sans 400/500 + JetBrains Mono for rails & metadata.
Voice fit
"Closing Table." Written. Slow. Capital-letter opinions. Italic for mild subversion.
Archetype
Second-generation operators, landowners, HOA boards, estate managers.
Price signal
Premium. Named operator. Annual program.
Status
Shipped across 22 patterns. This is the Round 1 baseline.

Display face
Archivo Narrow Black — condensed, industrial, fleet-sign-legible. Archivo 500/700 for UI and KPIs.
Body / UI
Archivo 500 body, DM Mono for metadata strips and route codes.
Voice fit
Dispatch log. Numeric-first. Present tense, verbs forward. No italics, no em-dashes.
Archetype

Price signal
Per-visit, per-route, contract. Volume is the proof.
Color posture
Utility surface (bone), ink (near-black), one high-vis accent (`#d9f24a`). Deliberately off Oxford's lawn-green — this is a different SKU, not a skin.

Status

Class C · Emergency-urgent Sketch · Archetype: Storm Response / 24-Hr Tree & Turf
Active response · 2 crews dispatched · ETA 42 min

Tree on the roof.
We're on route.
Now.

Storm response, emergency tree removal, and turf triage across Chester, Delaware, and Montgomery counties. One number. Picks up in under 90 seconds, 24/7.

☎Call dispatch · 610-555-0199 ◆Text photos & address
● Dispatch LIVE — 4:22 AM Avg pickup 84 sec Crews on shift 3 of 3 Insured to $2M · PA #HIC-PA-082417
Display face
Inter Tight Black — tight tracking, signal-flat, reads at distance and at panic-speed. IBM Plex Mono for alerts, dispatch codes, CTAs.
Body / UI
Inter Tight 500 body, IBM Plex Mono for buttons and statuses.
Voice fit
Radio dispatch + 911 intake. Short. Imperative. Never poetic. Numbers do the heavy lifting (ETA, pickup time, coverage limit).
Archetype
Storm response, emergency tree removal, after-hours turf + irrigation. Adjacent SKUs but share the 3 AM moment.
Price signal
Call-out fee + hourly. Priced for urgency, not consideration.
Color posture
Near-black surface, signal-orange primary (`#ff5a3d`), hazard-yellow under-stroke (`#ffd23f`). Pulsing status dot. Diagonal stripe texture. Deliberate "active-site" feel.
Patterns that port
stat-row-editorial (reskinned as live-status strip), chip-selector-form, service-area-ledger-dark (as "coverage grid"), trust-band-marquee.
Patterns that don't
Most of the library. Editorial voice, pull quotes, soil metaphor, magazine chrome, dropcap prose, review theme index — all off-brand for this class.
Failure mode
Easy to become a Craigslist ad. Guardrail is the numeric honesty: real pickup times, real coverage map, real license numbers. Cut the numbers and it collapses.
Status
Sketch. Tone is high-risk — recommend pressure-testing with 1 real prospect before committing to Class C as a productized offer.

Class B scope
Is "Operations-forward" a real Oxford product line (sub-brand for commercial / fleet work), or a template we sell to a different operator entirely? The type class is the same answer either way — the commercial question isn't.
Class C scope
Same. Emergency storm response adjacent to Oxford's core is plausible (tree work, irrigation triage). A standalone "24-Hr Response" SKU is a different bet.
What's missing
These sketches show headline + supporting strip + proof block only. Full nav, footer, service pages, and photography direction are not in scope for Round 1 typographic-class work per your direction.
